# Simon Game

## Overview
The Simon Game is a classic memory game where players must repeat a sequence of colors generated by the game. The game increases in difficulty as the player progresses through levels.

## Files
- **src/game.js**: Contains the main JavaScript logic for the game, tracking the game state, handling user input, generating sequences, playing sounds, and animating button presses.
- **sounds/**: Directory containing sound files used in the game, played when buttons are clicked or when the user makes a mistake.
- **index.html**: The main HTML document that sets up the structure of the game, including buttons and the display for the current level.
- **style.css**: Contains styles for the game, defining the appearance of buttons and other elements.

## How to Play
1. Press any key to start the game.
2. The game will generate a sequence of colors that you must repeat by clicking the corresponding buttons.
3. If you click the correct buttons in the correct order, the game will add another color to the sequence.
4. If you make a mistake, a sound will play, and the game will reset.

## Installation
1. Clone the repository to your local machine.
2. Open `index.html` in a web browser to start playing the game.
