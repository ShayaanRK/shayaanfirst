# Pricing Plan Layout

A simple frontend project that displays a pricing plan layout using HTML and CSS. This layout showcases different subscription plans with their features and a sign-up button.

## 🖥️ Technologies Used
- HTML
- CSS
- JavaScript

## 📌 Features
✔️ Responsive design  
✔️ Three pricing tiers (Basic, Standard, Premium)  
✔️ User-friendly layout  
✔️ Styled buttons for sign-up  

## 🚀 Getting Started
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/pricing-plan-layout.git
   ```
2. Open `index.html` in your browser.
